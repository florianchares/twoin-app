# Two-In — application Android

## Télécharger

**[⬇ Télécharger la dernière version (APK)](https://github.com/florianchares/twoin-app/releases/latest/download/two-in.apk)**

Toutes les versions : [Releases](https://github.com/florianchares/twoin-app/releases)

## Installer

1. Téléchargez `two-in.apk` sur votre téléphone Android.
2. Ouvrez le fichier. Si Android le demande, autorisez l'installation d'applications depuis cette source (navigateur ou gestionnaire de fichiers).
3. Lancez **Two-In**.

Les mises à jour s'installent par-dessus la version précédente : vos données sont conservées.
